## Design Context

### Users
Mac users manage everyday utilities from one menu-bar app. Sound provides per-app listening volume/output and an explicitly started virtual microphone mix for calls.

### Brand Personality
Compact, calm and consistent. Anton requires the existing Hop UI kit throughout the app.

### Aesthetic Direction
Monospaced utility interface, neutral controls, restrained accents, dark and warm light themes. Reuse Theme, SettingChip and MiniSlider. Do not introduce separate large controls, native-blue checks, extra headings or long descriptions.

### Design Principles
- Use the same components, spacing and hover behavior across modules; hover highlights rather than dims buttons.
- Muted and disabled slider thumbs use solid gray ink; never make the track visible through the thumb.
- Windows fit content and stay on screen; user resizing and full-screen take precedence.
- Volume readouts edit only after an explicit click. State labels and action changes must not move neighboring controls.
- Distinguish incoming app activity, listening mute and virtual-microphone capture. Opening a window does not start capture.

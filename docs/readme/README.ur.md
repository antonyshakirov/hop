- Homebrew: `brew install --cask antonyshakirov/tap/hop`
- `Hop-x.y.z.zip` — وہی ایپ سادہ آرکائیو کے طور پر (اندرونی اپ ڈیٹر اسی کو استعمال کرتا ہے)؛ [تازہ ترین ریلیز](https://github.com/antonyshakirov/hop/releases/latest) دیکھیں
- تیز مرر: [hop-dl.b-cdn.net/products/hop/Hop.dmg](https://hop-dl.b-cdn.net/products/hop/Hop.dmg)

macOS 15 یا اس سے نئے پر پہلی بار چلانے پر: ایک بار Hop کھولنے کی کوشش کریں،
پھر **System Settings ← Privacy & Security ← Open Anyway** میں جا کر **Open**
کی تصدیق کریں۔ Hop کو Apple کی توثیق حاصل نہیں، کیونکہ Apple Developer
Program کی رکنیت اس کے مصنف کے لیے دستیاب نہیں۔ کوڈ عوامی ہے، اور اندرونی
اپ ڈیٹس کی تصدیق Ed25519 سے ہوتی ہے۔ macOS 14 یا اس سے نیا درکار ہے۔

میڈیا بھی روک سکتی ہے۔ اور گنتی ختم ہونے پر ایک آواز بجتی ہے اور ہندسے تب تک

اوپر کا سوئچ آج، ہفتہ یا سب کچھ دکھاتا ہے۔ چلتا ہوا کام اُس دورانیے کو صفر سے
گنتا ہے جس میں آپ ہیں؛ ساتھ والا ✓ اُس دورانیے کو بند کر دیتا ہے اور قطار میں
پھر مدت کا مجموعہ آ جاتا ہے۔ کوئی کام کھولیں تو اُس کے سارے وقتی حصے سامنے ہوں
گے: دورانیہ یا وقت بدلیں، وہ سیشن شامل کریں جو کسی نے نہیں ناپا، یا کوئی سطر
حذف کریں؛ ہاتھ سے کی گئی درستیاں بھی اسی فہرست میں ہیں، اس لیے سطریں اوپر والے
مجموعے کے برابر رہتی ہیں۔ کوئی کام بہت دیر چلتا رہ جائے تو آٹھ گھنٹے بعد ایک
پٹی یاد دلاتی ہے۔ ساتھ ہی الگ کاموں کی فہرست رہتی ہے، جس میں مکمل شدہ نیچے چلے
جاتے ہیں۔

کسی کام پر کلک کریں تو اس کی سطر کھل جاتی ہے: پہلی سطر میں پورا متن، نیچے تفصیل، اور
پسندیدہ کے لیے ایک ستارہ۔ کسی کام کے ساتھ یاد دہانی بھی لگ سکتی ہے — دن، وقت اور دہرانے
کے لیے ہفتے کے جو دن چاہیں — اور وقت آنے پر Hop بتا دیتا ہے: «بعد میں» اور «مکمل» والا
بینر، آواز، اور مینو بار کا نشان؛ ہر ایک الگ سے چلتا ہے۔

**کام آپ کا اے آئی ایجنٹ بھی شامل کر سکتا ہے۔** فہرست ایک عام JSON فائل ہے اور Hop چلتے

اوپر کی ہر اجازت اس لیے ہے کہ کوئی خاصیت کام کرے، اور کسی اور مقصد کے لیے
نہیں۔ اور آپ کو اس پر یقین کرنا بھی نہیں پڑتا: Hop اوپن سورس ہے، سو وہ کوڈ جو
جمع کرتا، سرے سے موجود ہی نہیں — اسی ریپو میں پڑھ لیجیے۔ ایپ کی معلومات والی
ونڈو میں «ایپ کی اجازتیں» کا ٹیب اسی فہرست اور ہر اجازت کی موجودہ حالت کے
ساتھ موجود ہے۔

ویب سائٹ: [antonshakirov.com/products/hop](https://www.antonshakirov.com/products/hop)

## مفت، اور کیوں

Hop بالکل مفت ہے — نہ آزمائشی مدت، نہ پرو درجہ، نہ ایپ کے اندر خریداری۔ نہ
اشتہار، نہ ڈیٹا جمع کرنا، نہ اکاؤنٹ: یہاں کمانے کو کچھ نہیں اور بیچنے کو
کچھ نہیں۔ یہ ایک ذاتی منصوبہ ہے — میں نے Hop اپنے لیے بنایا، روز استعمال
کرتا ہوں، اور بانٹتا ہوں۔ کام آئے تو آگے بڑھا دیجیے۔ اور اگر حصہ ڈالنا چاہیں،
تو اب Hop کی مدد کا ایک راستہ ہے — خالص تحفہ، جس کے پیچھے کچھ بند نہیں۔

## ماخذ سے بنانا

Swift Package Manager، macOS 14 یا اوپر، بغیر کسی بیرونی انحصار کے:

```bash
git clone https://github.com/antonyshakirov/hop.git
cd hop
swift build
./scripts/build-app.sh
```

ڈیولپمنٹ کا طریقہ، ریلیز پائپ لائن اور رویّے کی تفصیلات
[docs/development.md](../development.md) اور
[docs/spec.md](../spec.md) میں ہیں۔

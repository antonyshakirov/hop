Hop อาศัยอยู่บนแถบเมนูของ Mac และเข้ามาแทนที่ยูทิลิตี้เล็ก ๆ หลายตัว:
ตัวจับเวลาสไตล์ Pomodoro การติดตามเวลาพร้อมรายการสิ่งที่ต้องทำ
ตัวกันเครื่องหลับแบบ caffeinate มอนิเตอร์ระบบ ตัวจัดการคลิปบอร์ด
ตัวแปลงไฟล์แบบลากมาวาง ตัวจัดหน้าต่าง และไคลเอนต์ทอร์เรนต์ตัวเบา —
แอปเนทีฟเบา ๆ หนึ่งตัว โดยจัดวางโมดูลที่คุณใช้ในแท็บได้สูงสุดสี่แท็บบนไอคอน

## ดาวน์โหลด

- **[Hop.dmg](https://github.com/antonyshakirov/hop/releases/latest/download/Hop.dmg)** — เปิดแล้วลาก `Hop.app` ไปยังโฟลเดอร์ Applications (แนะนำ)
- Homebrew: `brew install --cask antonyshakirov/tap/hop`
- `Hop-x.y.z.zip` — แอปตัวเดียวกันในรูปแบบไฟล์บีบอัดธรรมดา (ตัวอัปเดตในตัวใช้ไฟล์นี้) ดูได้ที่[รีลีสล่าสุด](https://github.com/antonyshakirov/hop/releases/latest)
- มิเรอร์ความเร็วสูง: [hop-dl.b-cdn.net/products/hop/Hop.dmg](https://hop-dl.b-cdn.net/products/hop/Hop.dmg)

Hop เซ็นด้วย Apple Developer ID และผ่านการรับรองจาก Apple แล้ว macOS
จึงเปิดได้เหมือนแอปทั่วไป ซอร์สโค้ดเปิดเผยต่อสาธารณะ
และการอัปเดตในตัวตรวจสอบด้วย Ed25519 ต้องใช้ macOS 14 ขึ้นไป

## ฟีเจอร์

### พื้นที่

ไอคอนรองรับแท็บได้สูงสุดสี่แท็บ และคุณลากแต่ละโมดูลไปยังแท็บที่ต้องการ:
ตัวจับเวลาไว้แท็บหนึ่ง มอนิเตอร์อีกแท็บ ส่วนที่ไม่ค่อยเปิดก็เก็บไว้ข้าง ๆ
ชั้น «ไม่ใช้งาน» จะเก็บสิ่งที่คุณพักไว้โดยไม่ลบทิ้ง

### ตัวจับเวลาและรอบทำงาน

นาฬิกานับถอยหลังแบบดอตแมทริกซ์ที่ตั้งได้ในท่าเดียว: ลากตัวเลข
พิมพ์เวลาเหมือนกดไมโครเวฟ หรือเลือกพรีเซ็ต มีรอบทำงาน-พัก
(Pomodoro 25/5, 52/17, 90/15 — หรือกำหนดเองก็ได้) นาฬิกาจับเวลา
ช่องพักตัวจับเวลาที่กำลังเดินอยู่ระหว่างที่คุณลองตัวอื่น
และการแจ้งเตือนเมื่อหมดเวลาที่หยุดสื่อที่กำลังเล่นให้ได้ด้วย เมื่อนับถอยหลัง
จบ จะมีเสียงดังหนึ่งครั้ง และตัวเลขจะกะพริบจนกว่าคุณจะรีเซ็ต

### ติดตามเวลาและสิ่งที่ต้องทำ

งานสามารถจัดเข้ากลุ่มโปรเจกต์ได้ แต่ละกลุ่มมีผลรวมของตัวเอง
และสวิตช์เหนือรายการเลือกวันนี้ สัปดาห์นี้ หรือทั้งหมด
งานที่กำลังเดินอยู่จะนับช่วงที่ทำอยู่ตั้งแต่ศูนย์ เครื่องหมาย ✓ ข้างๆ
จะปิดช่วงนั้น แล้วแถวกลับไปแสดงผลรวมของช่วงเวลา
เปิดงานแล้วจะเห็นทุกช่วงเวลาที่สะสมไว้ แก้ความยาวหรือเวลา
เพิ่มช่วงที่ลืมกดจับเวลา หรือลบบางแถวได้ การแก้ด้วยมืออยู่ในรายการเดียวกัน
ตัวเลขทุกแถวจึงรวมเท่ากับผลรวมด้านบนเสมอ ถ้างานไหนเดินนานเกินไป
พอครบแปดชั่วโมง จะมีแบนเนอร์เตือน ข้าง ๆ กันมีรายการสิ่งที่ต้องทำแยกต่างหาก
ที่งานเสร็จแล้ว จะจมลงไปด้านล่าง

คลิกที่งานแล้วแถวจะเปิดออก: ข้อความเต็มในบรรทัดแรก คำอธิบายด้านล่าง และดาวสำหรับรายการโปรด
สิ่งที่ต้องทำยังตั้งการเตือนได้ — เลือกวัน เวลา และวันในสัปดาห์ที่จะให้ทำซ้ำ — เมื่อถึงเวลา Hop จะบอกคุณ
ด้วยแบนเนอร์ที่มี «เลื่อน» และ «เสร็จแล้ว» เสียง และเครื่องหมายบนแถบเมนู ซึ่งเปิดแยกกันได้

**เอเจนต์ AI ของคุณก็เพิ่มงานได้เช่นกัน** รายการเป็นไฟล์ JSON ธรรมดา และ Hop อ่านการแก้ไขได้ขณะทำงาน
Hop ยังรันคำสั่งจากไฟล์และเข้าใจลิงก์ `hop://` ด้วย เอเจนต์เดียวกันนี้ หรือ Shortcut ที่สร้างจากลิงก์นั้น
จึงสั่งเริ่มจับเวลา เพิ่มงานพร้อมการเตือน หรืออ่านว่ากำลังทำอะไรอยู่ได้ ดู
[docs/automation.md](../automation.md)

### ตัวแปลงไฟล์

ลากรูปภาพ PDF วิดีโอ หรือไฟล์เสียงทั้งชุดมาวางบนแผง: ส่งออกเป็น JPEG, PNG,
HEIC, AVIF และ WebP บีบอัด PDF ย่อวิดีโอด้วย HEVC พร้อมการประเมินขนาด
แบบเรียลไทม์ที่ตรงไปตรงมาก่อนแปลงจริง ทุกอย่างประมวลผลในเครื่องทั้งหมด
วิดีโอยังจัดกรอบใหม่ได้ตอนแปลง — 9:16, 4:5, จัตุรัส หรือ 16:9 โดยครอบตัด
ใส่แถบ หรือวางบนสำเนาที่เบลอของตัวเอง — และการบีบอัดมีระดับของตัวเอง
ขนาดที่บอกไว้ก่อนแปลงจึงเป็นขนาดที่ได้จริง

ปุ่มเดียวจัดคลิปให้พร้อมสำหรับปลายทาง — reels, feed, tiktok, shorts หรือ
youtube — โดยตั้งกรอบภาพ ความละเอียด และการบีบอัดตามที่แพลตฟอร์มแนะนำเอง
พร้อมแสดงบิตเรตที่ได้ข้างแถบเลื่อน ส่วน MKV และ WebM จะถูกบรรจุใหม่เป็น MP4
ก่อน (macOS เปิดไม่ได้ทั้งคู่) ด้วยตัวช่วยขนาดเล็กที่ดาวน์โหลดครั้งเดียว
เอกสาร Pages, Numbers และ Keynote ส่งออกเป็นชุดโดยแอปเอง: เป็น PDF หรือ docx,
xlsx และ pptx

### ทอร์เรนต์

ไคลเอนต์ BitTorrent ตัวเบาในแผงเดียวกัน: ลากไฟล์ .torrent มาวาง
หรือวางลิงก์ magnet เลือกได้เป๊ะ ๆ ว่าจะดาวน์โหลดไฟล์ไหนบ้าง —
ก่อนเริ่มหรือแม้แต่ระหว่างดาวน์โหลดก็ยังได้ — หยุดชั่วคราว ทำต่อ
และปล่อยซีด พร้อมตัวเลือกหยุดอัตโนมัติเมื่อเรโชถึง 1.0

### ไฟล์บีบอัด

แถวของโมดูลจะเปิดหน้าต่างขึ้นมา และการวางไฟล์ทำในหน้าต่างนั้น — ⌘V ก็ใช้ได้ และวางได้หลายไฟล์พร้อมกัน
สิ่งที่เพิ่มเข้ามาจะรออยู่ในรายการจนกว่าคุณจะกดปุ่ม ไฟล์บีบอัดจะถูกแตก ส่วนที่เหลือจะรวมเป็นไฟล์บีบอัดเดียว
ผลลัพธ์จะไปที่เดสก์ท็อปโดยค่าเริ่มต้น หรือจะให้อยู่ข้างไฟล์เดิมหรือโฟลเดอร์ที่คุณเลือกก็ได้ รองรับ zip, rar,
7z, tar, tar.gz, tar.bz2, tar.xz และ gz ส่วน rar กับ 7z จะดาวน์โหลดตัวช่วยเล็ก ๆ (~6 MB) พร้อมตรวจลายเซ็น
ในครั้งแรกที่เจอ Hop แตก rar ได้แต่ไม่เคยสร้าง เพราะเป็นรูปแบบปิด «ให้ Hop เป็นค่าเริ่มต้นของไฟล์บีบอัด» ในการตั้งค่าจะเสนอเฉพาะ rar เมื่อไม่มีแอปของ Apple ดูแล
และดึง rar กลับจากแอปภายนอกได้ ส่วน zip, 7z และรูปแบบมาตรฐานยังอยู่กับ Archive Utility ใช้ได้แม้ซ่อนโมดูล
และการ์ดแสดงสถานะจริง ดับเบิลคลิกไฟล์บีบอัดใน Finder จะแตกไฟล์ไว้ข้าง ๆ ไฟล์นั้นเลย พร้อมหน้าต่างแสดงความคืบหน้าเล็ก ๆ ของตัวเอง และหากล้มเหลวก็ไม่เหลืออะไรซ่อนไว้ ไฟล์ที่ Hop เปิดจะมีไอคอนของตัวเองที่เขียนชื่อรูปแบบไว้ ทำให้ดูทั้งโฟลเดอร์ออกในพริบตา

### เอกสาร

### VPN

VPN ทุกตัวที่ Mac ของคุณรู้จัก พร้อมสวิตช์ของแต่ละตัว ไม่ว่าจะยี่ห้อใด Hop อ่านรายการนี้จากการตั้งค่าระบบโดยตรง
ไคลเอนต์ที่เพิ่งติดตั้งเมื่อวานจะโผล่มาเอง ที่ถอนออกก็หายไป ไม่มีอะไรต้องเพิ่มหรือตั้งค่าที่นี่

เชื่อมต่อและตัดการเชื่อมต่อได้โดยไม่ต้องเปิดอะไรเลย ขณะที่อุโมงค์ทำงานอยู่ จะมีจุดเล็ก ๆ ติดอยู่ที่มุมไอคอนบนแถบเมนู ข้าง ๆ ไฟแสดงสถานะอื่น เป็นสีเขียวขณะที่ยังมีอะไรผ่าน และเปลี่ยนเป็นสีส้มเมื่ออุโมงค์เปิดอยู่แต่ไม่มีอะไรกลับมา การเชื่อมต่อที่ตายเงียบ ๆ จึงไม่ดูเหมือนใช้งานได้ และแผงจะบอกว่าเป็นแถวไหน กดที่ชื่อแล้วหน้าต่างของ VPN นั้นจะเปิดขึ้นเมื่อคุณต้องการ พอปิดหน้าต่าง Hop จะปิดแอปให้
การเชื่อมต่อยังอยู่ เพราะอุโมงค์อยู่กับระบบ ไม่ใช่กับแอป

แถวนี้แสดงสิ่งที่ไคลเอนต์รายงานเอง คือชื่อของมัน และในวงเล็บคือสิ่งที่การตั้งค่าเพิ่มเข้ามา ซึ่งมักเป็นประเทศ
Hop จะไม่เดาประเทศจากที่อยู่เซิร์ฟเวอร์ เพราะทะเบียนที่อยู่บอกว่าช่วงหมายเลขจดทะเบียนที่ไหน ไม่ได้บอกว่าเครื่องตั้งอยู่ที่ใด

จุดนี้ปิดได้ในตั้งค่า โมดูลและสวิตช์ยังทำงานเหมือนเดิม

### แอป

ตารางของโปรแกรมที่คุณเปิดทั้งวัน อยู่ห่างแค่คลิกเดียวโดยไม่ต้องเข้าโฟลเดอร์แอปกด + แล้วเลือก หรือลากมาจาก Finder แถวหนึ่งวางได้เก้าตัว สูงสุดแปดแถว

ลากไอคอนเพื่อย้ายที่ เส้นสีเหลืองจะบอกว่ามันจะแทรกอยู่ระหว่างไอคอนคู่ไหน ส่วนไอคอนอื่นจะขยับเองเหมือนหน้าจอหลัก ปุ่มแก้ไขทำให้ไอคอนโยกเบา ๆ แต่ละอันมี ✕ และตั้งชื่อตารางเองได้ ถ้าคุณจำแอปได้จากหน้าตาอยู่แล้ว ก็ปิดชื่อใต้ไอคอนได้ตรงนั้น จะมีกี่ตารางก็ได้ งานไว้พื้นที่หนึ่ง ที่เหลือไว้อีกพื้นที่ แต่ละอันมีแอปของตัวเอง

## ความเป็นส่วนตัว — และทำไมให้สิทธิ์ได้อย่างสบายใจ

**Hop ไม่เก็บอะไรเลย ทั้งตอนนี้และต่อไป** ไม่มีเซิร์ฟเวอร์ของตัวเอง ไม่มีการวิเคราะห์ ไม่มีเทเลเมทรี
ไม่มีบัญชี ไม่มีการส่งรายงานข้อผิดพลาด ทุกสิทธิ์ด้านล่าง macOS จะถามก็ต่อเมื่อคุณใช้ฟีเจอร์ที่ต้องใช้มันจริง ๆ
และมันมีไว้เพื่อให้ฟีเจอร์นั้นทำงานเท่านั้น ไม่มีการเก็บอะไรแถมไปด้วย คุณไม่ต้องเชื่อคำพูด
เพราะแอปเป็นโอเพนซอร์ส และโค้ดที่จะเก็บข้อมูลนั้นไม่มีอยู่จริง ลองค้นหา SDK ติดตามผู้ใช้
หรือการเรียกใช้ระบบวิเคราะห์ในรีโพนี้ดู คุณจะไม่พบเลย

ทุกอย่างทำงานในเครื่อง: ไม่มีเซิร์ฟเวอร์ ไม่มีระบบวิเคราะห์ ไม่มีบัญชี
แอปเชื่อมต่อเครือข่ายเฉพาะตอนตรวจหาอัปเดต ตอนที่คุณรันทดสอบความเร็วในตัว
และ — ถ้าคุณเปิดใช้โมดูลทอร์เรนต์ — ตอนดาวน์โหลดเอนจินครั้งเดียว
กับตอนรับส่งทราฟฟิกทอร์เรนต์เองเท่านั้น การตรวจหาอัปเดตจะส่งเฉพาะเวอร์ชันที่คุณใช้อยู่
ไม่มีข้อมูลที่ระบุตัวคุณหรือเครื่อง Mac ของคุณ อัปเดตและเอนจินทอร์เรนต์
ถูกส่งเป็นไฟล์บีบอัดที่ลงลายเซ็นไว้ และตรวจสอบด้วยลายเซ็น Ed25519
ก่อนติดตั้งทุกครั้ง

## สิทธิ์

Hop จะขอสิทธิ์ก็ต่อเมื่อคุณใช้ฟีเจอร์ที่ต้องใช้สิทธิ์นั้นจริง ๆ และในหน้าต่างข้อมูล
ของแอปมีรายการสิทธิ์ทั้งหมดพร้อมสถานะปัจจุบัน:

- **เครือข่าย — antonshakirov.com** — ตรวจหาและดาวน์โหลดอัปเดต รวมถึงตัวช่วยเสริม
  สองตัว (เอนจินทอร์เรนต์และตัวบีบอัด 7-Zip)
- **เครือข่าย — ทอร์เรนต์, ทดสอบความเร็ว** — ทราฟฟิกกับผู้ใช้อื่นเมื่อเปิดโมดูล
  ทอร์เรนต์ ส่วนการทดสอบความเร็วใช้ networkQuality ของ macOS วัดกับเซิร์ฟเวอร์ Apple
- **การช่วยการเข้าถึง** — การวางลงในแอปที่อยู่ข้างล่าง ตัวจัดการหน้าต่าง และการล็อก
  คีย์บอร์ด
- **การบันทึกหน้าจอ** — เฉพาะโมดูลการอ่านข้อความ และเฉพาะตอนครอบพื้นที่ หลอดดูดสีไม่ต้องใช้
- **การแจ้งเตือน** — เสียงเตือนของตัวจับเวลา และทอร์เรนต์ที่เสร็จแล้ว
- **รหัสผ่านผู้ดูแลระบบ** — ครั้งเดียว สำหรับโหมดปิดฝา (pmset ต้องใช้ root)
- **เปิดตอนเข้าสู่ระบบ** — ปิดไว้จนกว่าคุณจะเปิดเอง

ตอนเปิดแอปไม่ขอสิทธิ์อะไรเลย และจะไม่ขอเพื่อโมดูลที่คุณยังไม่ได้เปิด
ไม่มีการวิเคราะห์ ไม่มีเทเลเมทรี ไม่มีบัญชี ไม่มีการส่งรายงานข้อผิดพลาด
แอปติดต่อ antonshakirov.com เพียงเพื่อถามว่ามีเวอร์ชันใหม่หรือไม่ และดาวน์โหลดมัน
หรือหนึ่งในตัวช่วยสองตัวเมื่อคุณตกลงเท่านั้น ที่เหลือทั้งหมดอยู่ในเครื่อง Mac นี้:
ประวัติคลิปบอร์ด เวลาที่จับได้ รายการสิ่งที่ต้องทำ ข้อความที่อ่านได้ และสีที่ดูดมา

ทุกสิทธิ์ด้านบนมีไว้เพื่อให้ฟีเจอร์ทำงานได้เท่านั้น ไม่มีอย่างอื่น และคุณไม่ต้องเชื่อคำพูด
เพราะ Hop เป็นโอเพนซอร์ส โค้ดที่จะเก็บข้อมูลนั้นไม่มีอยู่จริง อ่านได้ในรีโพนี้ ในหน้าต่างข้อมูลของแอป
มีแท็บ «สิทธิ์ของแอป» ที่แสดงรายการเดียวกันพร้อมสถานะปัจจุบันของแต่ละสิทธิ์

เว็บไซต์: [hop.tools](https://hop.tools)

## ฟรี และทำไมถึงฟรี

Hop ฟรีอย่างสมบูรณ์ ไม่มีช่วงทดลอง ไม่มีเวอร์ชันโปร ไม่มีการซื้อในแอป ไม่มีโฆษณา ไม่มีการเก็บข้อมูล ไม่มีบัญชี จึงไม่มีอะไรให้หารายได้และไม่มีอะไรให้ขาย นี่เป็นโปรเจกต์ส่วนตัว ผมทำ Hop ขึ้นเพื่อใช้เอง ใช้มันทุกวัน และแค่แบ่งปันให้ทุกคน ถ้ามันมีประโยชน์ ก็ช่วยบอกต่อด้วยนะ และถ้าอยากช่วยสนับสนุน ตอนนี้ก็มีช่องทางสนับสนุน Hop แล้ว — เป็นเพียงของขวัญ ไม่มีสิ่งตอบแทนใด ๆ

## บิลด์จากซอร์สโค้ด

Swift Package Manager, macOS 14+, ไม่มี dependency ภายนอก:

```bash
git clone https://github.com/antonyshakirov/hop.git
cd hop
swift build
./scripts/build-app.sh
```

ขั้นตอนการพัฒนา ไปป์ไลน์รีลีส และสเปกพฤติกรรมของแอปอยู่ใน
[docs/development.md](../development.md) และ [docs/spec.md](../spec.md)
